# Security policy

## Supported versions

Security fixes are provided for the latest stable 1.x release. Users should upgrade to 1.0.4.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository, or contact the maintainer privately through the contact method on the maintainer's GitHub profile if private reporting is unavailable.

Include the affected version, impact, reproduction steps, and any proposed mitigation. Please allow a reasonable period for investigation and coordinated disclosure. You will receive acknowledgement when the report is reviewed; publication timing will be coordinated when the report is confirmed.

Never include production credentials, connection strings, database dumps, or customer job payloads in a report.
