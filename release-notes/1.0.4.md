# DevDad.Hangfire.Oracle 1.0.4

This backward-compatible stabilization release retains .NET 8 support and adds the .NET 10 build while preserving the package ID, assembly, namespace, and 1.0.3 public API.

Highlights:

- Versioned, idempotent schema installation and automatic data-preserving migration from a complete 1.0.3 schema.
- Oracle-compatible concurrent queue acquisition, fetch ownership tokens, sliding invisibility, crash recovery, and safe requeue/remove behavior.
- Correct atomic counter aggregation and accurate raw-plus-aggregated statistics.
- Owner-aware renewable distributed locks with table and `DBMS_LOCK` modes.
- Corrected monitoring DTOs, pagination, state handling, TTL cleanup, timeout, time, and rollback behavior.
- Current production dependencies and removal of unused `Dapper.Oracle`.
- Reproducible packages with Source Link, XML docs, symbols, locked restore, NuGet compatibility validation, and comprehensive Oracle 23 integration tests.

Before upgrading, stop all workers and back up the Hangfire schema. Start one 1.0.4 instance to perform the migration before restarting the fleet. Oracle Database 19c or later is required. See `UPGRADE.md` for details.
